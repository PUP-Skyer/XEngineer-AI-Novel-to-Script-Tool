# XEngineer-AI-Novel-to-Script-Tool
一款 AI 辅助剧本创作工具，旨在降低小说改编剧本杀的门槛。核心能力：(1) AI 根据提示词自动生成多章节小说；(2) 将小说一键转换为结构化 YAML 剧本，自动生成 4-8 个角色（含性格、背景、秘密、动机）和 5-10 个场景（含对白、旁白、选择分支）；(3) 可视化剧本编辑器，支持 Monaco Editor 实时预览 YAML；(4) 多人在线剧本杀游戏引擎，支持 AI NPC 扮演。技术栈：React 18 + Vue 3 + NestJS + TypeORM + Socket.IO + BullMQ。Monorepo 架构，含完整 YAML Schema 设计文档。
